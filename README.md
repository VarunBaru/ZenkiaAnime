# Zenkia Anime

A Japanese-inspired anime discovery, reading, and streaming platform with a sleek manga-style interface.

## Features
- **Watch**: Stream and track episode progress.
- **Read**: Explore manga and related materials.
- **Explore**: Discover top anime, genres, and personalized watchlists.
